Security and privacy

Official-portal style flow

This flow references the official SOA portal and can open it in a new tab, but the actual import happens through our backend-controlled SOA session.

No stored password

Your password is never stored in localStorage, sessionStorage, Firestore, logs, or backups.

Retry safely

If the session expires or the CAPTCHA becomes invalid, fetch a fresh CAPTCHA and try again. Previously imported data stays available inside the app.

Fallback options

If live import is unavailable right now, you can still continue with demo data or open previously imported SOA data that is already saved to your account.
