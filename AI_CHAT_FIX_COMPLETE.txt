┌──────────────────────────────────────────────────────────────────────────────┐
│ API SPECIFICATION                                                             │
└──────────────────────────────────────────────────────────────────────────────┘

📥 REQUEST: POST /api/ai/chat

Headers:
  Content-Type: application/json
  Authorization: Bearer <token>  ← OPTIONAL (works without it!)

Body:
  {
    "message": "User's question",     ← Primary field
    "question": "User's question",    ← Backward compatibility
    "context": "Optional context",    ← Optional
    "systemPrompt": "Custom prompt"   ← Optional
  }

📤 RESPONSES:

✅ 200 OK (Success)
  {
    "success": true,
    "response": "AI generated answer",
    "timestamp": "2025-12-11T04:50:11.308Z"
  }

❌ 400 Bad Request (Invalid input)
  {
    "success": false,
    "message": "Message is required"
  }

⚠️  503 Service Unavailable (No API key)
  {
    "success": false,
    "message": "AI service is currently unavailable. Please check if OPENROUTER_API_KEY is configured."
  }

❌ 500 Internal Server Error (Processing failure)
  {
    "success": false,
    "message": "Failed to process your request. Please try again.",
    "error": "Error details (dev mode only)"
  }
